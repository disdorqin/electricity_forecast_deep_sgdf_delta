# 电价预测模型改进实验总结

## 1. 实验目标
使用新数据 `shandong_pmos_hourly.csv`（2022-2026，更长的历史）改进实时电价预测模型。

## 2. 实验方法
所有实验都使用：
- **Walk-forward backtest**（按月滚动，避免数据泄漏）
- **Day-level sMAPE**（正确的评估指标，避免使用hourly sMAPE导致的错误结论）
- **DA-only baseline**（日前电价作为baseline）

## 3. 实验结果

### 3.1 实验A：直接预测RT价格（Ridge回归）
- **方法**：使用所有可用特征（44个），直接预测RT价格
- **结果**：
  - 平均模型sMAPE：24.05
  - 平均DA sMAPE：13.04
  - 平均改进：-11.01（负数表示模型比DA差）
  - 改进的月份：1/18
- **结论**：❌ 失败，线性模型无法预测RT价格

### 3.2 实验B：直接预测RT价格（HGB）
- **方法**：使用HistGradientBoostingRegressor（非线性模型），直接预测RT价格
- **结果**：
  - 平均模型sMAPE：19.53
  - 平均DA sMAPE：13.04
  - 平均改进：-6.49
  - 改进的月份：3/18
- **结论**：❌ 失败，非线性模型仍然无法预测RT价格

### 3.3 实验C：预测RT价格变化（Ridge回归）
- **方法**：预测RT价格的一阶差分（即RT价格的变化），然后RT_pred = DA + predicted_change
- **结果**：
  - 平均模型sMAPE：16.97
  - 平均DA sMAPE：13.09
  - 平均改进：-3.88
  - 改进的月份：2/17
- **结论**：❌ 失败，预测价格变化仍然无法超越DA

### 3.4 实验D：Residual预测（来自DeepRT-SOTA-3）
- **方法**：预测residual (RT - DA)
- **结果**：所有tabular模型都KILL（alpha=0，fallback到DA）
- **结论**：❌ 失败，residual不可预测

## 4. 失败原因分析

1. **RT价格方差太大**（std=222.19），模型难以预测
2. **特征信号太弱**，与residual相关性很低（|corr| < 0.15）
3. **DA-only是一个很强的baseline**，corr(RT, DA) = 0.85（DA捕捉了RT变化的85%）
4. **Residual不可预测**，自相关性很低（corr(residual, lag_24h) = -0.0266）

## 5. 可能的改进方向

### 5.1 方向A：概率预测（分位数回归）
- **方法**：预测RT价格的分位数（如5%, 50%, 95%分位数）
- **优势**：可以提供RT价格的可能范围，更有价值
- **劣势**：仍然可能无法超越DA-only baseline

### 5.2 方向B：深度学习模型（LSTM/Transformer）
- **方法**：使用更长的序列长度（如168h=1周），训练LSTM或Transformer模型
- **优势**：可以捕捉长期依赖和非线性关系
- **劣势**：训练时间长，可能仍然无法超越DA-only baseline

### 5.3 方向C：集成学习
- **方法**：集成多个模型（如Ridge + HGB + LSTM）
- **优势**：可能提高预测精度
- **劣势**：仍然可能无法超越DA-only baseline

### 5.4 方向D：接受DA-only，转而改进其他方面
- **方法**：
  1. 接受DA-only是一个很强的baseline
  2. 转而改进其他方面，如特征工程、模型解释性等
  3. 或者，创建一个混合模型（DA-only + 简单修正）
- **优势**：更实际，可以避免无止境的实验
- **劣势**：可能无法满足"改进"的要求

## 6. 建议

根据所有的实验结果，**DA-only可能是一个很难超越的baseline**。

**建议的策略**：
1. **优先尝试方向A**（概率预测），因为：
   - 可以提供更有价值的信息（RT价格的可能范围）
   - 即使无法超越DA-only的point forecast，也可以提供不确定性估计

2. **如果方向A失败，则尝试方向D**（接受DA-only，转而改进其他方面），因为：
   - 继续在无意义的方向上浪费时间可能没有意义
   - 可以转而改进其他方面，如模型解释性、特征重要性等
